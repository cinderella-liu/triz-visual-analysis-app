# TRIZ Visual Analysis App Roadmap

## V1: TRIZ Case Inbox

Goal: collect and manage analysis cases.

- Create a case
- Save case locally
- View recent cases
- Edit core fields
- Delete cases
- Chinese UI

## V2: Contradiction Analysis

Goal: convert a problem into a TRIZ contradiction model.

- Technical contradiction form
- Physical contradiction form
- Improving/worsening parameter fields
- Inventive principle recommendations
- Contradiction cards
- Analysis progress stages
- Static theory analysis map

Status: implemented in the local V2 app.

## V3: Visual Analysis Graph

Goal: make the product visibly useful.

- Problem-to-solution graph
- Graph node detail panel
- Node drag and zoom
- Basic graph layout
- PNG export

## V4: AI Assisted Analysis

Goal: reduce manual modeling effort.

- Extract problem elements from natural language
- Suggest contradictions
- Recommend TRIZ tools
- Draft analysis reports

## V5: Case Knowledge Base

Goal: turn one-off analysis into reusable knowledge.

- Case tags
- Industry templates
- Similar case search
- Solution outcome records
- Team case library
